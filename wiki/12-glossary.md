# Glossary

| Term | Meaning |
|---|---|
| Secondary use | Using electronic health data for the Chapter IV purposes, other than the purpose they were collected for (Art. 2(2)(e)). Opposite of primary use (care of the patient). |
| Electronic health data | Personal or non-personal health data in electronic form (Art. 2(2)(c)). |
| Personal electronic health data | Data concerning health and genetic data in electronic form (Art. 2(2)(a)). Pseudonymised data are still personal. |
| Non-personal electronic health data | Anonymised data that no longer relate to an identifiable person, or data that never did (Art. 2(2)(b)). |
| Anonymised | Cannot be linked back to a person. Statistics after the small-cell rule are treated as anonymised in this app. |
| Pseudonymised | Direct identifiers replaced by a code (here `patient_id`); re-linking information stays with the access body (Art. 66(3)). Still personal data. |
| Health data access body (HDAB) | Public body that decides applications and requests and provides data (Art. 55, 57). This app plays its role. |
| Health data holder | Organisation holding the data; here the three hospitals Klinikum Nord, Süd and West. |
| Health data applicant | Person or organisation asking for data. |
| Health data user | Applicant who has been granted access (Art. 2(2)(u)). |
| Health data request | Request for an answer in anonymised statistical format only (Art. 69). |
| Health data access application | Application for access to data, possibly pseudonymised, under a data permit (Art. 67). |
| Data permit | Administrative decision allowing a user to process specified data for specified purposes (Art. 2(2)(v), Art. 68). |
| Secure processing environment (SPE) | Controlled environment where permitted data are processed and from which records cannot be downloaded (Art. 73). |
| Opt-out | A person's choice that their data are not used for secondary use (Art. 71). |
| Small-cell rule | This app's suppression rule for statistical answers (page 09). |
| HealthData@EU | The cross-border infrastructure for secondary use (Art. 75). Not used in this prototype. |
