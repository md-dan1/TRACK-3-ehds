# Writing reasons for applicants

The reason is shown to the applicant and to staff. Refusals must be justified to the applicant
(Art. 68(9); Art. 57(1)(j)(iii) requires decisions to be published with their justification).

## Style

- 1–3 short sentences, plain language, no legal jargon beyond the article number.
- Each sentence states one finding and ends with its article in brackets.
- Name the purpose or the prohibited use concretely ("setting insurance premiums"), not abstractly.
- Never repeat personal details, never mention patient counts below 10.
- No hedging and no apologies.

## Templates

| Outcome | Template |
|---|---|
| REJECT (54) | "Using health data to {prohibited use} is prohibited (Art. 54)." + optional second sentence for re-identification |
| REJECT (53, no purpose fits) | "The purpose '{short purpose}' is not one of the purposes for which health data may be used (Art. 53). Staff will review this decision." |
| APPROVE_STATISTICAL via request | "{Purpose phrase} (Art. 53). Statistics answer the question (Art. 69)." + "Small cells are suppressed." if applicable |
| APPROVE_SPE | "{Purpose phrase} (Art. 53). {Why patient-level data are needed}, so pseudonymised data is justified (Art. 66). Access only under a data permit inside a secure processing environment (Art. 68, 73)." |
| APPROVE_STATISTICAL via access application | "{Purpose phrase} (Art. 53). Statistics answer the question, so pseudonymised records are not justified (Art. 66). Approved as statistics instead (Art. 69)." |

## Examples

- "Drug safety monitoring is an allowed purpose (Art. 53). Statistics answer the question (Art. 69)."
- "Using health data to decide on loan conditions is prohibited (Art. 54)."
- "Selling alcoholic beverages is a harmful product use and is prohibited (Art. 54)."
- "Validating a diagnostic algorithm is an allowed purpose (Art. 53). Each patient's ECG recordings are needed, so pseudonymised data is justified (Art. 66). Access only under a data permit inside a secure processing environment (Art. 68, 73)."
- "Research is an allowed purpose (Art. 53). A table of rates answers the question, so pseudonymised records are not justified (Art. 66). Approved as statistics instead (Art. 69)."

## Article one-liners (tooltips)

| Art. | One-liner |
|---|---|
| 53 | Health data may be used only for listed purposes such as research, public health, policy, official statistics, teaching and better care. |
| 54 | Some uses are banned: decisions against people, insurance and employment decisions, advertising, harmful products. |
| 66 | Only the data needed are given, anonymised by default, pseudonymised only if anonymised data cannot work. |
| 67 | What an application for access to data must contain. |
| 68 | When a data permit is issued, and what it contains. |
| 69 | A health data request is answered only with anonymised statistics. |
| 71 | People can opt out; their data are then not used. |
| 73 | Permitted data are accessed only in a secure processing environment; records cannot be downloaded. |
